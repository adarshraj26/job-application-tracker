# Frontend - Job Application Tracker

This directory contains all the frontend-related files and folders for the Job Application Tracker project.

## Structure

- `src/` - React source code
- `public/` - Static assets
- `dist/` - Build output
- `node_modules/` - Frontend dependencies
- Configuration files:
  - `package.json` - Frontend dependencies and scripts
  - `vite.config.ts` - Vite configuration
  - `tsconfig.json` - TypeScript configuration
  - `tailwind.config.js` - Tailwind CSS configuration
  - `eslint.config.js` - ESLint configuration
  - `postcss.config.js` - PostCSS configuration
  - `components.json` - UI components configuration

## Deployment Files

- `netlify.toml` - Netlify deployment configuration
- `vercel.json` - Vercel deployment configuration
- `railway.toml` - Railway deployment configuration
- `railway.json` - Railway deployment configuration
- `deploy-netlify.sh` - Netlify deployment script
- `deploy-railway.sh` - Railway deployment script
- `vercel-build.sh` - Vercel build script

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```

## Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run preview` - Preview production build
- `npm run lint` - Run ESLint
- `npm run test` - Run tests
